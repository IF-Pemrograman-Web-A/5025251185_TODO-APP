# Deskripsi
## Deskripsi

Todo App merupakan App sederhana yangdibuat untuk membantu mahasiswa mencatat tugas perkuliahan. Website ini memunculkan tugas dari beberapa mata kuliah yang telah di catat oleh pengguna, sehingga pengguna dapat melihat tugas yang perlu dikerjakan dengan lebih awal.

Pada website ini terdapat dua bagian utama. Bagian kiri digunakan untuk menampilkan daftar tugas, sedangkan bagian kanan berisi form untuk menambahkan nama mata kuliah dan deskripsi tugas.

Website ini dibuat menggunakan HTML dan CSS. Dalam pembuatannya, saya menggunakan elemen HTML semantik seperti header, main, aside, dan footer, serta CSS Grid untuk mengatur tata letak halaman. Website juga dibuat responsif agar tampilannya dapat menyesuaikan ukuran layar laptop maupun HP.

## Fitur

1. **Daftar Tugas**
   Menampilkan beberapa tugas kuliah beserta nama mata kuliah dan deskripsinya.

2. **Form Tambah Tugas**
   Menyediakan tempat untuk mengisi nama mata kuliah dan deskripsi tugas.

3. **Layout Dua Panel**
   Membagi tampilan website menjadi dua bagian menggunakan CSS Grid, yaitu daftar tugas dan form tambah tugas.

4. **Desain Warna Ungu**
   Menggunakan warna ungu sebagai warna utama dengan background lavender dan panel berwarna putih.

5. **Responsive Design**
   Tampilan website dapat menyesuaikan ukuran layar laptop dan HP.

6. **HTML Semantik**
   Menggunakan elemen header, main, aside, dan footer agar struktur HTML lebih rapi.

7. **External CSS**
   Menggunakan file style.css terpisah untuk mengatur tampilan website.
